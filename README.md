## Descripcion de los Ejercicios

Cada ejercicio se encuentra estructurado en un proyecto independiente configurado con Java y Maven:

1. **Ejercicio 2.1 (Persona):** Modelado basico de atributos personales y metodos de impresion.
2. **Ejercicio 2.2 (Planeta):** Gestion de caracteristicas fisicas de planetas, tipos de planetas y calculo de densidad.
3. **Ejercicio 2.3 (Automovil):** Simulacion de un vehiculo, control de velocidades (acelerar, desacelerar, frenar) y calculo de tiempo de llegada.
4. **Ejercicio 2.4 (Suite Geometrica):** Jerarquia de figuras geometricas (Circulo, Rectangulo, Cuadrado y Triangulo Rectangulo) junto con la clase de prueba principal.
5. **Ejercicio 2.5 (Cuenta Bancaria):** Implementacion de metodos con parametros de entrada, tipos enumerados (`enum`) y validaciones logicas para consignaciones y retiros.
